## Notes

* **Sampler repeats.** A batch that straddles two passes over the training images can contain the same image twice
  (review F5). Harmless for training.
* **RAM.** `Cache.arm(512)` builds the 512 px arrays in memory (about 370 MB): count it in Kaggle's 29 GB.
* **Global environment.** Two OpenCV wheels are installed in the global Python (`opencv-python` 4.11.0.86 and
  `opencv-python-headless` 4.13.0.90); not changed. `requirements.txt` lists the headless one.
* **Python.** The local Python is 3.13.1; the Kaggle image's Python version was not printed on 2026-10-12.
* **Weights.** SMP 0.5.0 pins revision `7a57b34f723329ff020b3f8bc41771163c519d0c` of `smp-hub/resnet34.imagenet`; the
  Hugging Face `main` resolves to the same blob. With `make_dataset.py --with-weights` they can be shipped in the
  private dataset and loaded with the Internet off (verified locally: identical encoder weights).
* **Line endings.** LF in the repository (`.gitattributes`).
* **Local timing (RTX 3050, 512 px, batch 8, mixed precision, real cache, fold 0):** 0.309 s per step with the data
  loader in the main process, 0.285 s with two workers (smoke test, GPU only: 0.28 s). The loader is not the
  bottleneck. This is a measurement of the tool (`--measure-only`), not a result.
